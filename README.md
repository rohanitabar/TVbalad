# TV Bilad

TV Bilad is a service landing page for TV and home appliance repair services. This project is a static website built with HTML, CSS, and JavaScript. It does not require installing dependencies or running a build process.

## Getting Started

Open `index.html` in your browser.

To run the project using a local web server, execute the following command in the project directory:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Features

- Image sliders for the homepage and brand logos
- A vertical hamburger menu on tablet and mobile screens
- A fixed navigation bar that hides when scrolling down and reappears when scrolling up
- Service category sections and common TV problems
- An animation for the TV introduction section that triggers when it enters the viewport
- A responsive layout for different screen sizes

## Project Structure

```text
index.html                 Page content
assets/css/style.css       Styles and layout
assets/css/bootstrap.rtl.css
assets/js/app.js           Interactive functionality
assets/js/bootstrap.bundle.js
assets/img/                Images and logos
```

The Vazirmatn font and some statistics images are loaded from external sources, so an internet connection is required to display them. The main website images and Bootstrap files are included in the project.
